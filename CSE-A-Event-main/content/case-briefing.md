# DETECTRIX: Case Briefing
*Investigate. Connect. Decode. Unlock.*

---

## Event Overview & Objective

**DETECTRIX** is an intensive, team-based digital forensics investigation challenge for second-year CSE students. Each team of **4 members** investigates a fictional digital incident using printed log files and sector captures to solve 10 connected questions and discover the final **10-character access code**.

The event tests observation, logical reasoning, teamwork, attention to detail, memory, and problem-solving under time pressure.

---

## Event Details

| Attribute | Details |
|---|---|
| **Investigation Material** | Case briefing, log files, and data sector dumps |
| **Questions** | Exactly 10 Investigation Questions (Question 1 to Question 10) |
| **Hint Challenges** | 2 Hint Challenges (Two-Hand Shape & Memory Challenge) |
| **Final Output** | 10-Character Access Code |
| **Winning Criteria** | First team to successfully submit the correct code to the Mystery Box |
