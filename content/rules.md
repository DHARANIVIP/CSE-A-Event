# DETECTRIX: Official Event Rules & Guidelines
*Investigate. Connect. Decode. Unlock.*

Please review the official rules carefully before starting the investigation. All team members must adhere strictly to these guidelines.

---

### Rule 1: Team Composition & Eligibility
- Each team consists of **strictly 4 registered 2nd-year CSE students**.
- Substitutions or individual participation are prohibited.

### Rule 2: Manual Investigation & Permitted Tools
- Teams examine log files and connect related records.
- Permitted analytical tools include Python, pandas, SQL, Excel, terminal utilities (`grep`, `awk`), and AI tools on authorized workstations.
- No unauthorized external communication or inter-team collusion is permitted.

### Rule 3: The 10 Investigation Questions
- Participants must solve **10 investigation questions** (Question 1 to Question 10).
- Each question yields one character towards the final **10-character access code**.

### Rule 4: Hint Challenges
- **Hint Challenge 1 – Two-Hand Shape**: One team member simultaneously draws a triangle with one hand and a square with the other hand (one attempt only). Successful completion awards Hint 1.
- **Hint Challenge 2 – Memory Challenge**: One team member observes a short sequence of letters, numbers, and symbols and reproduces it from memory (one attempt only). Successful completion awards Hint 2.

### Rule 5: Access Code & Mystery Box Submission
- The final deduction produces a **10-character access code** (containing letters, numbers, and special characters).
- Enter the code into the Mystery Box portal.
- Correct code displays **"ACCESS GRANTED"**; incorrect code displays **"INVALID CODE"**.

### Rule 6: Winner Criteria
- The **first team** to successfully submit the correct 10-character code to the server will be declared the winner based on authoritative server timestamp.
